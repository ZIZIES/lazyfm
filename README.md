# lazyfm

a 20% cooler lazy tui file manager, with really pretty icons

![demo](demo.gif)

## install

cargo install --git https://github.com/ZIZIES/lazyfm

## keys

| key | does |
|---|---|
| `j`/`k` | down/up |
| `h`/`l` | parent/enter |
| `g`/`G` | top/bottom |
| `n` / `w` | new/close tab |
| `.` | toggle hidden files |
| `i` | cycle icon theme |
| `?` | help |
| `[` / `]` | switch tabs
